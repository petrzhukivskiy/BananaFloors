BANANA FLOORS — STATIC WEBSITE

Contents:
- index.html
- favicon.svg
- images/ (web-optimized flooring inspiration images)

Deployment on the current DigitalOcean Droplet:
1. Copy these files into your BananaFloors GitHub repository.
2. Commit and push to main.
3. On the Droplet run:
   cd /var/www/html
   git pull
